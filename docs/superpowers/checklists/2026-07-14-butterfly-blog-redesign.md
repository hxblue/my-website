# Butterfly 风格博客改版 Checklist

> 实现完成后逐项运行或观察。每项只有在取得对应证据后才能勾选；发现失败时先修复并重新验证。

## Implementation Completeness

- [ ] **AC1 / 双布局隔离**：`/blog` 与 `/blog/:slug` 使用统一博客外壳，`/` 与 `/projects` 仍使用原作品集外壳。（验证：依次访问四个地址并保存桌面截图，对比导航、背景和页脚；确认博客有返回作品集入口，作品集页面布局未改变。）
- [ ] **AC2 / 博客首屏**：博客首页显示大幅原创封面、站点名称、副标题和下滑入口。（验证：以 1440×1100 打开 `/blog`，观察首屏内容；点击下滑入口，确认文章区域进入视口。）
- [ ] **AC2 / Hero 降级**：博客首屏图片不可用时仍显示可读的渐变背景、名称和副标题。（验证：在开发者工具中阻止 Hero 图片请求并刷新，确认首屏结构和文字仍完整。）
- [ ] **AC3 / 桌面导航状态**：博客导航在 Hero 顶部为融合状态，向下滚动后转为固定高可读状态。（验证：在 1440px 视口记录滚动前后截图，确认导航位置稳定、文字清晰且页面无跳动。）
- [ ] **AC3 / 移动菜单**：390px 视口下菜单可展开、操作并收起，路由跳转后不会残留展开状态。（验证：使用鼠标和键盘各完成一次菜单打开、选择入口和关闭流程。）
- [ ] **AC4 / 文章顺序**：文章按发布日期从新到旧展示，置顶字段只显示标识而不改变日期顺序。（验证：使用日期明确的多篇测试数据，逐项核对显示顺序与原始日期。）
- [ ] **AC4 / 卡片信息**：每张文章卡片展示封面、标题、日期、摘要和标签，并按存在性展示分类、更新时间和置顶标识。（验证：对比一篇完整元数据文章和一篇仅含必填字段的文章，确认没有空标签或占位文本泄漏。）
- [ ] **AC4 / 交错与单列**：桌面端卡片图片左右交错，移动端统一为图片在上、正文在下。（验证：分别在 1440px 和 390px 截图，确认顺序与可读性。）
- [ ] **AC4 / 卡片链接**：点击卡片封面、标题或主要内容区域可进入正确 slug 的文章详情。（验证：从至少两张卡片进入详情，核对地址和标题一致。）
- [ ] **AC5 / 文字搜索**：标题、摘要和标签关键字均能筛选出正确文章。（验证：分别输入只存在于标题、摘要、标签中的三个关键字，并记录结果数量。）
- [ ] **AC5 / 组合筛选**：搜索、标签、分类和月份可以组合，结果同时满足全部条件。（验证：选择至少两个条件并人工核对每个结果；再增加第三个条件确认结果收窄。）
- [ ] **AC5 / 空结果恢复**：无匹配文章时显示明确说明并提供恢复全部文章的操作。（验证：输入不可能匹配的文本，点击重置，确认所有文章恢复且条件被清空。）
- [ ] **AC6 / 分页容量**：文章总数至少为 11 时，第一页最多 10 篇，第二页包含剩余文章。（验证：使用非提交的 11 篇验收数据，统计第一页和第二页卡片数量。）
- [ ] **AC6 / 分页与筛选联动**：在第二页修改任一筛选条件后返回第一页。（验证：进入第二页后选择标签，确认当前页语义和显示内容均回到第 1 页。）
- [ ] **AC6 / 切页定位**：切换分页后文章列表起点回到视口，而不是停留在页尾。（验证：在页面底部点击下一页并观察最终滚动位置；减少动态效果模式下重复一次。）
- [ ] **AC7 / 桌面侧栏**：桌面端显示作者信息、文章统计和最近文章；有数据时显示分类、标签云和月份归档。（验证：1440px 视口检查所有侧栏卡片及统计数与完整文章集合一致。）
- [ ] **AC7 / 侧栏操作**：最近文章进入正确详情，分类、标签和月份入口应用正确筛选。（验证：每类入口至少点击一个并核对页面结果和当前条件状态。）
- [ ] **AC7 / 移动侧栏**：移动端侧栏不挤压正文，并位于文章列表之后或等效移动区域。（验证：390px 视口从列表滚动到侧栏，确认正文保持单列且页面无横向滚动。）
- [ ] **AC8 / 文章 Hero**：文章详情显示封面、标题、发布日期、标签和返回博客入口；可选元数据按存在性显示。（验证：访问完整与最小元数据两篇文章并保存头部截图。）
- [ ] **AC8 / 文章封面降级**：文章封面缺失或失败时使用稳定渐变背景且标题仍可读。（验证：阻止封面请求，确认 Hero 高度、文字和返回入口不发生破坏性变化。）
- [ ] **AC9 / Markdown 覆盖**：标题、段落、列表、引用、表格、任务列表、图片、内部链接、外部链接、行内代码和围栏代码全部正确渲染。（验证：打开覆盖所有元素的验收文章，逐项观察且控制台无渲染错误。）
- [ ] **AC9 / 链接行为**：外部链接安全新开，内部链接保持站内当前标签页导航。（验证：检查外链具有 `target="_blank"` 和安全 rel，实际点击内外链接各一次。）
- [ ] **AC9 / 代码复制**：围栏代码显示语言和复制按钮，成功或失败均有可感知反馈。（验证：正常复制一次，再禁用 Clipboard 权限重试；确认两个结果均通过可见文字或辅助技术反馈。）
- [ ] **AC9 / 正文图片**：正文图片响应式缩放且失败时不造成横向滚动或正文崩塌。（验证：在 390px 视口检查宽图，再阻止一张图片请求并观察布局。）
- [ ] **AC10 / 目录生成**：二级和三级标题生成目录，重复标题产生唯一锚点，代码围栏中的 `##` 不进入目录。（验证：使用专门的目录验收 Markdown，比较目录数量、ID 和正文标题。）
- [ ] **AC10 / 目录交互**：桌面目录保持易于访问并高亮当前章节，点击目录项定位到对应标题。（验证：滚动经过至少三个章节，观察高亮变化并点击一个非当前章节。）
- [ ] **AC10 / 移动目录**：移动端目录可展开和收起且不长期占用正文宽度；无标题文章不显示空目录。（验证：390px 视口操作折叠目录，并访问无二三级标题文章。）
- [ ] **AC11 / 评论保留**：评论区位于正文之后，可加载已有评论并提交有效评论。（验证：打开已配置评论服务的文章，加载列表并提交一条验收评论，确认成功反馈和新评论出现。）
- [ ] **AC11 / 评论失败**：评论服务失败时显示可理解错误，正文和导航仍可使用。（验证：阻止评论接口请求后刷新或提交，确认错误提示且其他页面功能不受影响。）
- [ ] **AC12 / 明暗主题**：博客首页和详情在明暗主题下的导航、卡片、正文、代码、目录和评论均清晰可读。（验证：两页分别切换主题并保存截图，检查文字、边框、焦点和强调色。）
- [ ] **AC12 / 主题持久化**：主题选择在博客和作品集之间跳转以及刷新后保持一致。（验证：选择非默认主题，依次跳转 `/blog`、文章详情、`/` 并刷新。）
- [ ] **AC13 / 加载状态**：文章集合和详情请求期间显示与博客风格一致的加载状态。（验证：开发者工具设置慢速网络并刷新两页，观察加载反馈不闪烁错误内容。）
- [ ] **AC13 / 本地降级**：远程内容源不可用时仍显示本地文章列表和 `/blog/hello-world`。（验证：以不含 Notion 环境变量的开发会话启动，访问列表和详情。）
- [ ] **AC13 / 未找到**：不存在的 slug 显示明确未找到页面和返回博客入口，不静默跳转。（验证：访问 `/blog/does-not-exist`，核对地址保留、提示和返回入口。）
- [ ] **AC13 / 非关键图片失败**：头像、卡片封面或文章图片失败不阻断导航和正文。（验证：分别阻止三类图片请求，完成首页到详情的基本浏览流程。）
- [ ] **AC14 / 页面 Meta**：博客首页和不同文章具有对应 title、description 和 Open Graph 信息。（验证：在开发者工具 Elements 中检查 head，核对首页及两篇文章的值。）
- [ ] **AC14 / Meta 清理**：离开文章进入作品集后不残留文章标题、描述或分享图。（验证：从详情进入 `/`，检查 `document.title` 和相关 meta 已恢复。）

## Integration

- [ ] **路由集成**：`/`、`/projects`、`/blog`、`/blog/hello-world` 和不存在文章地址均能直接刷新访问。（验证：逐个在地址栏直接输入并刷新，确认没有空白页、服务器 404 或重定向循环。）
- [ ] **内容源集成**：远程文章和本地 Markdown 被转换为同一 UI 数据结构，新增 Notion 属性缺失时旧文章不报错。（验证：分别打开一篇远程文章和本地文章，比较必要字段与控制台错误。）
- [ ] **首页最近文章集成**：作品集首页最近文章与博客首页使用相同远程优先/本地降级逻辑。（验证：在远程可用和不可用两种会话中比较首页和博客首页的文章标题。）
- [ ] **主题集成**：博客复用现有 `ThemeProvider`，不存在第二套互相冲突的主题状态。（验证：检查一次切换能同时更新根 `.dark` 状态、博客变量和 localStorage，跨布局保持同步。）
- [ ] **评论集成**：视觉改版没有改变评论 slug，旧文章评论仍关联原文章。（验证：检查 `hello-world` 加载的评论仍使用 `hello-world`，提交后刷新仍存在。）
- [ ] **筛选统计集成**：侧栏文章总数、标签数和分类数来自完整集合，不随当前分页或筛选错误减少。（验证：记录未筛选统计，应用无结果筛选后确认总统计仍代表完整集合。）
- [ ] **目录渲染集成**：目录 ID 与 `react-markdown` 实际标题 ID 一致，页面中不存在重复 ID。（验证：在控制台统计 `[id]` 重复值并点击每个目录链接抽样检查。）
- [ ] **样式隔离**：博客 `.blog-shell` 样式没有改变作品集首页、项目区和全局 Header。（验证：与实施前截图对比 `/` 和 `/projects` 的主要布局、颜色和排版。）
- [ ] **资源集成**：Hero 使用原创或授权资源，仓库不包含参考站图片、头像或下载缓存。（验证：检查 `public/images/blog` 来源和 Git diff，搜索 `cognipix` 仅允许出现在规格文档引用中。）

- [ ] **AC15 / 1440px**：1440×1100 下双栏比例、sticky 侧栏和目录正常。（验证：滚动首页及详情，观察 sticky 元素不覆盖页脚或正文。）

## Performance

- [ ] **AC16 / Hero 优先级**：博客首屏主视觉优先加载且无明显布局跳动。（验证：Network 面板禁用缓存后刷新，确认 Hero 请求优先且首屏尺寸在图片完成前已保留。）
- [ ] **AC16 / 图片懒加载**：首屏之外的卡片封面和正文图片初始不全部请求。（验证：Network 面板清空后刷新，未滚动前检查请求；滚动到对应位置后请求出现。）
- [ ] **图片格式与尺寸**：本地 Hero 为适合网页的 WebP 且尺寸不低于 1600×900，没有加载明显超出需求的多份原图。（验证：检查文件属性、Network transferred size 和实际展示尺寸。）
- [ ] **无持续高负载动画**：页面不包含持续运行的 Canvas/粒子循环，静止时主线程没有周期性长任务。（验证：检查 DOM 无全屏 canvas，并在 Performance 面板空闲录制 5 秒观察。）
- [ ] **构建体积无异常**：博客改版没有引入新的动画运行时或 Markdown 插件大包。（验证：比较构建输出与依赖清单，确认 `package.json` 未新增未批准运行时依赖，构建警告中无异常大 chunk。）
