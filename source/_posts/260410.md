## 121 买卖股票的最佳时机


![image.png](/images/posts/260410/b02186954610.png)


### 贪心做法


```javascript
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        int first = 0;
        int ans = 0 ;
        for(int i = 1 ;i < n ;i++){
            if(prices[i] > prices[first]){
                ans = Math.max(prices[i] - prices[first] , ans);
            }else{
                first = i;
            }
        }

        return ans;
    }
}
```


说是贪心感觉也想模拟的过程，总是贪心的希望在股票价格低的时候买进，然后再在高价的时候卖出，这个从前向后只买一次让这个解决办法变得简单了。


### 动态规划


这题目似乎还可以用动态规划的做法


```java
class Solution {
    public int maxProfit(int[] prices) {
        if (prices == null || prices.length == 0)
            return 0;
        int len = prices.length;

        int[][] dp = new int[len][2];
        // 0 持有股票
        // 1 不持有股票

        dp[0][0] = -prices[0];
        dp[0][1] = 0;

        for (int i = 1; i < len; i++) {
            dp[i][0] = Math.max(dp[i - 1][0], -prices[i]);
            dp[i][1] = Math.max(dp[i - 1][1], dp[i - 1][0] + prices[i]);
        }

        return dp[len - 1][1];
    }
}
```


dp[i][0]  第i天持有股票最多能赚多少钱


dp[i][1]   第i天不持有股票最多能赚多少钱

## 45 跳跃游戏2 


![image.png](/images/posts/260410/545de45ef85f.png)


从贪心的角度想，这个每次跳跃肯定是跳跃的越多越好，但是跳的大的话可能会到达不了最后


```java
public int jump(int[] nums) {
        int len = nums.length;
        if(len == 1 ) return 0 ;

        int index = 0 ;
        int maxcount = index + nums[index];
        int ans = 1 ;

        while(index < len && maxcount < len - 1 ){
           int next_index = -1 ;
           if(maxcount >= len - 1 ) break;

           for(int i = index + 1 ;i < maxcount ;i++){
              if(nums[i] + i > maxcount){
                 next_index = i ;
                 maxcount = nums[i] + i;
              }
           }

           ans ++ ;
           index = next_index;

        }

        return ans ;

    }
}
```


我的贪心代码总是写的很混乱

## 763 划分字母空间


![image.png](/images/posts/260410/5254ce61ffeb.png)


思路也是很好想的。尽可能的找到前面出现的，先是a  ，那就尽可能的找到后面最后出现的a ,如果没有就找第二个b的最后出现位置


但是，该如何快速锁定呢？？？？


```java
import java.util.LinkedList;
import java.util.List;

class Solution {
    public List<Integer> partitionLabels(String s) {
        List<Integer> ans = new LinkedList<>();
        int[] edge = new int[26];
        char[] chars = s.toCharArray();
        for (int i = 0; i < chars.length; i++) {
            edge[chars[i] - 'a'] = i;
        }

        int idx = 0;
        int last = -1;
        for (int i = 0; i < chars.length; i++) {
            idx = Math.max(edge[chars[i] - 'a'], idx);
            if (idx == i) {
                ans.add(idx - last);
                last = idx;
            }
        }

        return ans;
    }
}
```


这样的方法很奇妙哦，edge数组存储所有字符最后一次出现的位置。
